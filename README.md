> **A Protective Formula for Strong Passwords**

Transform your online security with RakshaSutra, a military-grade password generator that combines ancient wisdom with cutting-edge cryptography. Named from Sanskrit meaning "protective formula," this extension delivers uncompromising password security through two proven algorithms used by tech giants.

### ❔ Why Choose RakshaSutra?
Unlike basic password generators that use simple randomization, RakshaSutra employs the same sophisticated algorithms used by Apple's Keychain and enterprise password managers. Whether you need convenience (Easy Type) or maximum security (Max Security), RakshaSutra delivers both without compromise.

Install RakshaSutra today and experience the difference that true cryptographic security makes for your digital safety.

> **Privacy Promise:** No data is ever collected, stored, or transmitted. Your passwords are generated locally and never leave your device.

## 🚀 Features

### 🔒 Easy Type Mode

- **Apple-style syllable patterns** for pronounceable passwords
- 20-character passwords with 71+ bits of entropy
- Perfect for manual entry on gaming consoles, smart TVs, and IoT devices
- Example: `diksyq-qe9xec-teXdug`

### ⚡ Max Security Mode

- **GitHub/Microsoft-style** fully random passwords
- Customizable length (8-32 characters)
- Optional special characters
- 47-210 bits of entropy
- Example: `2.go2E$1X~4W.DAH~9q7iN7ox]$t:$?4`

### 🌟 Core Features

- ✅ **Cryptographically Secure** - Uses Web Crypto API with rejection sampling
- ✅ **Zero Data Collection** - Completely offline and private
- ✅ **Real-time Entropy Display** - See password strength instantly
- ✅ **One-Click Copy** - Instantly copy to clipboard
- ✅ **Modern UI** - Clean, intuitive dark theme interface
- ✅ **Cross-browser Compatible** - Works on Firefox, Chrome, Edge, and more

## 🔐 Security

RakshaSutra implements enterprise-grade security practices:

- **True Random Generation**: Uses `crypto.getRandomValues()` for cryptographic randomness
- **Modulo Bias Elimination**: Implements rejection sampling to prevent statistical bias
- **No Network Requests**: All processing happens locally in your browser
- **No Data Collection**: Zero telemetry, analytics, or tracking
- **Open Algorithm**: Uses industry-standard password generation methods

### Entropy Comparison

| Method                  | Length   | Charset Size      | Entropy (bits) | Security Level |
| ----------------------- | -------- | ----------------- | -------------- | -------------- |
| Easy Type               | 20 chars | Syllable-based    | 75             | Strong ✅      |
| Max Security (16 chars) | 16 chars | 90 (with special) | 104.9          |Strong ✅ |
| Max Security (32 chars) | 32 chars | 90 (with special) | 209.7          | Very Strong ✅     |

> NIST recommends 60+ bits of entropy for strong passwords. RakshaSutra exceeds this in all modes.

## 📖 Usage

1. **Click** the RakshaSutra icon in your browser toolbar
2. **Choose** between Easy Type or Max Security mode
3. **Customize** settings (Max Security mode only)
4. **Click** "Generate Password" button
5. **Copy** with one click and use your secure password
